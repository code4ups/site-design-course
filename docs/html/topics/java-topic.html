Java – Εισαγωγή στον Προγραμματισμό

Η Java είναι μία από τις πιο δημοφιλείς και αξιόπιστες γλώσσες προγραμματισμού παγκοσμίως. Χρησιμοποιείται σε εφαρμογές για κινητά (Android), web εφαρμογές, λογισμικό επιχειρήσεων και πολλά ακόμα. Είναι γλώσσα αντικειμενοστραφούς προγραμματισμού (Object-Oriented Programming – OOP) και αποτελεί εξαιρετική επιλογή για όποιον θέλει να αποκτήσει γερές βάσεις στον προγραμματισμό.

Τι είναι η Java;

Η Java είναι μια γλώσσα υψηλού επιπέδου που αναπτύχθηκε από την Sun Microsystems (σήμερα ανήκει στην Oracle). Έχει σχεδιαστεί ώστε να είναι φορητή: γράφεις τον κώδικα μία φορά και τρέχει σε οποιοδήποτε σύστημα που έχει εγκατεστημένο το Java Virtual Machine (JVM).

  • Είναι αντικειμενοστραφής, με έμφαση στην επαναχρησιμοποίηση κώδικα.
  • Χρησιμοποιείται σε τεράστιες πλατφόρμες (Android, server apps, τράπεζες, επιχειρήσεις).
  • Προσφέρει ασφάλεια, σταθερότητα και υψηλή απόδοση.

Απλό Παράδειγμα Java

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Γειά σου Κόσμε!");
    }
}

Το παραπάνω πρόγραμμα εκτυπώνει το μήνυμα Γειά σου Κόσμε!. Η μέθοδος main είναι το σημείο εκκίνησης κάθε εφαρμογής Java.

Βασικές Έννοιες στην Java

  • Κλάσεις & Αντικείμενα: Η βάση του αντικειμενοστραφούς προγραμματισμού.
  • Μεταβλητές & Τύποι Δεδομένων: Η Java είναι στατικά τυποποιημένη, δηλαδή πρέπει να δηλώνεις τον τύπο.
  • Μέθοδοι: Συναρτήσεις που εκτελούν συγκεκριμένες ενέργειες μέσα σε κλάσεις.
  • Δομές Ελέγχου: if, for, while για λογική ροή και επαναλήψεις.

Πώς να ξεκινήσεις με Java

  1. Κατέβασε και εγκατέστησε το Java Development Kit (JDK).
  2. Χρησιμοποίησε ένα IDE (π.χ. IntelliJ IDEA, Eclipse ή NetBeans).
  3. Δημιούργησε ένα νέο αρχείο .java και ξεκίνα να γράφεις τον πρώτο σου κώδικα!

Άσκηση για Εξάσκηση

Γράψε ένα πρόγραμμα Java που:

  1. Ζητάει το όνομα και την ηλικία σου από το χρήστη.
  2. Υπολογίζει πόσο θα είσαι μετά από 10 χρόνια.
  3. Εκτυπώνει ένα μήνυμα με το αποτέλεσμα.

Παράδειγμα:

import java.util.Scanner;

public class AgeCalculator {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Πώς σε λένε; ");
        String name = input.nextLine();
        System.out.print("Πόσο χρονών είσαι; ");
        int age = input.nextInt();

        int futureAge = age + 10;
        System.out.println(name + ", σε 10 χρόνια θα είσαι " + futureAge + " χρονών!");
    }
}

Συχνά Λάθη Αρχαρίων στην Java

  • Ξεχνούν το ; στο τέλος των εντολών.
  • Μπερδεύουν τύπους δεδομένων (π.χ. int, double, String).
  • Δεν δηλώνουν σωστά τη μέθοδο main.
