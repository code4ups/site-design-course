Python – Εισαγωγή στον Προγραμματισμό

Η Python είναι μία από τις πιο δημοφιλείς και εύχρηστες γλώσσες προγραμματισμού στον κόσμο. Χρησιμοποιείται για ανάπτυξη εφαρμογών, ανάλυση δεδομένων, τεχνητή νοημοσύνη, web development και πολλά άλλα. Ο καθαρός και απλός συντακτικός της κανόνας την καθιστά ιδανική για αρχάριους αλλά και για επαγγελματίες.

Τι είναι η Python;

Η Python είναι μια διερμηνευόμενη, δυναμική γλώσσα προγραμματισμού υψηλού επιπέδου.

  • Είναι απλή και ευανάγνωστη – μοιάζει με την αγγλική γλώσσα.
  • Εκτελείται γραμμή-γραμμή (interpreted language), χωρίς compilation.
  • Διαθέτει μεγάλη κοινότητα και άπειρες βιβλιοθήκες (π.χ. NumPy, Pandas, Django).
  • Χρησιμοποιείται από μεγάλες εταιρείες (Google, Netflix, NASA).

Απλό Παράδειγμα Python

# Αυτό είναι το πρώτο σου πρόγραμμα Python
name = input("Πώς σε λένε; ")
print("Γεια σου, " + name + "!")

Η Python χρησιμοποιεί τη συνάρτηση input() για να πάρει δεδομένα από τον χρήστη και τη συνάρτηση print() για να εμφανίσει αποτελέσματα στην οθόνη.

Βασικές Έννοιες στην Python

  • Μεταβλητές: Αποθηκεύουν τιμές χωρίς να χρειάζεται να δηλώσεις τύπο (x = 10).
  • Συναρτήσεις: Ορίζονται με def και οργανώνουν τον κώδικα.
  • Δομές Ελέγχου: if, for, while για αποφάσεις και επαναλήψεις.
  • Λίστες & Dictionaries: Βασικές δομές δεδομένων της Python.

Πώς να ξεκινήσεις με Python

  1. Κατέβασε την Python από το επίσημο site.
  2. Χρησιμοποίησε έναν απλό editor (VS Code, PyCharm, ή ακόμα και το IDLE της Python).
  3. Άνοιξε ένα νέο αρχείο .py και ξεκίνα να γράφεις κώδικα.

Άσκηση για Εξάσκηση

Γράψε ένα πρόγραμμα Python που:

  1. Ρωτάει το όνομά σου και την ηλικία σου.
  2. Υπολογίζει σε ποιο έτος θα γίνεις 100 χρονών.
  3. Εκτυπώνει ένα μήνυμα με αυτή την πληροφορία.

Παράδειγμα:

name = input("Πώς σε λένε; ")
age = int(input("Πόσο χρονών είσαι; "))

year_100 = 2025 - age + 100
print(name + ", θα γίνεις 100 χρονών το έτος " + str(year_100))

Συχνά Λάθη Αρχαρίων στην Python

  • Ξεχνούν την εσοχή (indentation) – η Python απαιτεί σωστή στοίχιση.
  • Χρησιμοποιούν λάθος εισαγωγικά ή μπερδεύουν το = με το ==.
  • Ξεχνούν να μετατρέψουν τύπους δεδομένων (π.χ. int() σε αριθμούς).
